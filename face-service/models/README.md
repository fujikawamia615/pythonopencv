模型文件不提交至 Git。运行 `python face-service/download_models.py` 下载并校验。

来源：OpenCV Zoo 的 YuNet 2023mar 与 SFace 2021dec，分别用于检测和特征提取。

- https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet
- https://github.com/opencv/opencv_zoo/tree/main/models/face_recognition_sface

第三方模型的权利与使用条件以对应模型目录中的 LICENSE 为准。更换模型后必须清空已有特征并重新录入；不同模型生成的特征不能混用。
