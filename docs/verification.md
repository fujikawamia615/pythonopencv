## 常见问题

### Python 显示未就绪

确认 `face-service/models/` 下有两个完整 `.onnx` 文件。执行下载脚本检查哈希，然后 `docker compose restart face-service`。通过日志确认不是 LFS 指针、损坏权重或挂载路径错误。

### Docker 端口被占用

把 `compose.yaml` 的 `127.0.0.1:8080:80` 改为例如 `127.0.0.1:8088:80`，重启 frontend 后访问对应端口。本机开发时 Java 和 Vite 使用不同端口（8080 / 5173）。

### Java 启动失败

检查 Java 版本、MySQL 数据库和用户、DB_PASSWORD、Redis 地址、FACE_SERVICE_KEY、ADMIN_PASSWORD。直接运行时需要在 IDE 或当前终端设置变量，根目录 `.env` 不会自动被 Spring Boot 读取。

### 改了管理员密码仍无法登录

管理员只在空数据库时初始化。修改 `.env` 不会覆盖现有 BCrypt 哈希。开发时可在确认数据可丢弃的独立环境重新初始化；有数据的环境应通过明确的密码重置流程维护，不能直接把明文写入 `password_hash`。

### 同一个人识别失败

使用另一张正面、无遮挡、光照均匀的清晰照片。检查是否正确录入、模型是否被更换。默认阈值只是演示起点，应采集经授权的正负样本建立验证集，再评估误识率与拒识率，不能只用同一张照片说明准确率。

### npm / Maven / pip 下载失败

确认网络可以访问各自的官方仓库；根据本机网络设置受信任的代理或镜像。项目不提交个人代理、访问令牌或开发机密码。
